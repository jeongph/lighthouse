# 주석 컨벤션

## 형식

```
TAG: yyyy-MM-dd 내용
```

## 태그 종류

| 태그 | 의미 |
|------|------|
| `TODO` | 해야 할 작업, 아직 구현하지 않은 기능 |
| `FIXME` | 알려진 버그 또는 잘못된 동작, 반드시 수정 필요 |
| `XXX` | 더 생각해봐야 할 부분, 비효율적이거나 의문이 드는 코드 |

## 예시

```java
// TODO: 2026-06-13 페이지네이션 처리 추가
// FIXME: 2026-06-13 입력이 null일 때 NPE 발생, 검증 필요
// XXX: 2026-06-13 이중 루프로 O(n^2), 자료구조 개선 검토
```
