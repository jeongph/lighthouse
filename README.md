# lighthouse

> 흩어진 깃허브·프로젝트·네이밍룰을 정리해 바로 찾아갈 수 있게 안내하는 `등대`.

## 워크스페이스 구조

```
lighthouse/                  ← 워크스페이스 루트 (github.com/jeongph/lighthouse)
├── CLAUDE.md                ← Claude Code 최상위 지침
├── .gitignore
├── README.md
├── .claude/
├── docs/
│   ├── conventions/         ← 컨벤션 문서
│   └── ...                  ← 기타 문서 (커밋 예시·참고 등)
└── repositories/            ← 레포지토리 모음 (각각 독립 git)
    └── ...
```
